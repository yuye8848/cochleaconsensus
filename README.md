# CochleaConsensus

Uniformly reanalysed cross-study resource of animal hearing-loss models (mouse + zebrafish regeneration contrast), v1.0 frozen 2026-10-29.

- Website: https://yuye8848.github.io/cochleaconsensus/ (custom domain cochlea.erbihou.org pending DNS)
- Data package (Zenodo): https://doi.org/10.5281/zenodo.23754507 (concept DOI 10.5281/zenodo.23754506)
- Site source is generated from the frozen Step 1-5 analysis products; the live site is served from the `gh-pages` branch of this repository.
